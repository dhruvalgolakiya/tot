Everything TOT does, area by area, with an honest status:

- **Available**: works today.
- **Partly**: works, with something missing, and the line says what.
- **Not yet**: planned, not built. The [Not yet](/docs/not-yet) page has more.

## Agents and chats

More in [Agents and chats](/docs/agents).

- [Available] **Agents with mascots.** As many as you like, each with a mascot, instructions, a default model and a computer.
- [Available] **Claude and ChatGPT on your own plans.** TOT Auto, and a switch to the other provider when a plan hits its limit.
- [Partly] **Mascot moods.** Mascots show working, idle and asleep. They don't act out thinking or talking yet.
- [Available] **Attachments.** Images, text and code files, and anything else copied to the agent's computer.
- [Partly] **Voice input.** Works in the browser over HTTPS. Not in the Mac app, and not in Firefox.
- [Available] **Forks and attached chats.** Fork a chat, bring it back, and attach other chats with `@`.
- [Available] **Knowledge.** A notebook per agent, shared knowledge, Learn a repo, and the wiki keeper.
- [Available] **Routines.** Scheduled work, each run in a new chat.

## Tasks

More in [Tasks](/docs/tasks).

- [Available] **Background tasks** with live cards in your chat.
- [Available] **Steer, pause, resume and stop**, on Claude and ChatGPT.
- [Available] **The queue.** Limits per agent and overall, reordering, Run now, and a pause when a provider keeps failing.
- [Available] **Restarts.** Running tasks pick up again after TOT restarts.
- [Available] **Hearing back.** The chat replies when its tasks finish; toasts, browser notifications, Slack and email threads.
- [Available] **Splitting work.** Roles, model tiers, one combined answer, and limits on how much starts.
- [Available] **Switching providers mid-task** when a plan hits its limit.
- [Not yet] **Playbooks that drive tasks.** Step-by-step recipes with plan approval and an automatic independent review are set up, but don't run tasks yet.

## Projects

More in [Projects](/docs/projects).

- [Available] **Three kinds**: a GitHub repo, a folder on your Mac (with your OK), or a topic.
- [Available] **Several repos in one project**, any mix of GitHub repos and folders, one task per repo.
- [Available] **A Lead chat per project.** Plans the work, starts, steers, stops and watches tasks across the project's repos, and lands only with your OK, by a card that waits for you.
- [Available] **Subscriptions.** The Lead hears about pull requests (checks, reviews, comments, merges), tickets and schedules on its own, and pushes review fixes to a draft PR only with your OK.
- [Available] **One screen.** The project page is just the Lead chat, with New chat, Repos and Knowledge in its menu, and a row for every project on each agent's home screen.
- [Available] **Tickets and intake.** Linear and GitHub links, Slack channels and Linear teams.
- [Not yet] **Folder projects on cloud computers.** Folders on your Mac need a local computer.

## Mission control

More in [Mission control](/docs/mission-control).

- [Available] **Starting work**: just ask in a chat — the agent (or a project's Lead) starts tasks itself — plus `/best-of` to run two attempts and compare.
- [Available] **The board**, with overlaps and the order to land in.
- [Available] **Landing code**: Review & land, Merge into main, draft PR, Update from main, Discard.
- [Available] **Best of two**, with a side-by-side compare and Keep this one.
- [Available] **Checks** from the project's own commands, run when a task finishes.
- [Available] **Worktrees that work**: setup, files to copy, ports and cleanup.
- [Partly] **Preview.** Opens a task's dev server, on local computers only.
- [Not yet] **Following a PR after it's open**: CI checks, review comments, updating the branch, ready for review.
- [Not yet] **Stacked PRs.**

## Memory

More in [Memory](/docs/memory).

- [Available] **About you and per project**, as git repos of markdown. A project's is one knowledge base with its wiki: facts, pages and each repo's own docs.
- [Available] **History and Undo** for every change, to a fact or a page.
- [Available] **Keeps itself current.** After a task lands, when a repo's main branch moves, from chats, and in Dreaming, with Undo on each update.
- [Available] **Dreaming**, a nightly tidy-up you can undo.
- [Available] **Sync between your Macs**, for About you, and an optional git backup.
- [Not yet] **Project knowledge on more than one Mac.**

## Computers

More in [Computers](/docs/computers).

- [Available] **A local sandboxed folder** per agent.
- [Available] **Cloud computers** on boat.dev, with desktop control you can watch.
- [Partly] **Sharing a web server.** A public link on cloud computers; a `localhost` link on local ones.

## Phone and other computers

More in [Use it from your phone and other computers](/docs/devices).

- [Available] **Remote access**: a password, Tailscale or Wi‑Fi, and a QR code for your phone.
- [Available] **Signed-in list**, with sign-out for each device.
- [Available] **Pairing Macs** to use each other's agents, live.
- [Partly] **Your phone.** A web app on your home screen. No iPhone or Android app.
- [Not yet] **Moving an agent** to another Mac.
- [Not yet] **Working across Macs**: an agent starting a task on another Mac, previews from other screens, and reading an offline Mac's chats.
